# Privacy policy

YouPls (web app, installed web app and desktop programs) **does not collect, transmit or store any personal data**.

- **No data leave your computer.** There are no accounts, no telemetry, no analytics, no tracking, no cookies and no advertising. Data files, models and results are processed locally in your browser or in the desktop program. They stay on your computer: in the browser's local storage and in files you save yourself.
- **Network access** happens only when you open a link, for example to the documentation, the GitHub repository or the releases page. Otherwise the program loads only its own files, from GitHub Pages or from its installation.
- **The website** is hosted on GitHub Pages. GitHub may process technical request data (such as IP addresses) as described in the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). YouPls itself sets no cookies and runs no scripts from third parties.
- **Deleting local data:** clear the site data in your browser, or uninstall the program.
